# Estudos de C++

Meu caderno de estudos de **C++**: exercícios, anotações e pequenos projetos, organizados por módulo.

## Como está organizado

```
01-fundamentos/      sintaxe, tipos, controle de fluxo
02-estruturas/       listas, dicionários, funções, módulos
03-projetos/         pequenos projetos que juntam o que aprendi
```

Cada pasta ganha um `README.md` curto com o que foi estudado e o que aprendi. As pastas são criadas conforme o estudo avança.

## Como rodar um exercício

```bash
g++ -std=c++17 -o exemplo 01-fundamentos/exemplo.cpp
./exemplo
```
